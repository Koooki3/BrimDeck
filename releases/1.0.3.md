New
- Added Grok Bot as a quota source. It shows the weekly allowance, reset time and plan of the account signed in to the Grok Bot desktop app.
- The Cursor quota now includes a Grok Bot row.

Improvements
- Antigravity quotas now use the same row layout as other tools. Click the column to switch between Gemini and Claude quotas.
- Antigravity models whose names carry a suffix such as a reasoning level now use the price of their base model, for more accurate cost estimates.
- A first install now creates only a desktop shortcut, and an update keeps the shortcuts that already exist.

Fixes
- Reduced blurry text in the panel and popups on some displays, depending on resolution and scaling.
- Fixed the clock in the collapsed bar sitting slightly too high.
- Fixed delayed song change notices for NetEase Cloud Music, other players briefly appearing when a browser changes songs, and missing lyrics for some songs.
- Removed redundant tooltips from the plan chip and from the app and model names in the token usage table.

新功能
- 新增 Grok Bot 配额来源，显示 Grok Bot 桌面版登录账户的每周额度、重置时间和套餐。
- Cursor 配额中新增 Grok Bot 额度显示。

改进
- Antigravity 额度改为与其他工具相同的行样式，点击该列可在 Gemini 和 Claude 额度之间切换。
- Antigravity 中带有推理等级等后缀的模型，改为使用其基础模型的价格，使价格计算更准确。
- 首次安装时默认只创建桌面快捷方式，更新时保留已有的快捷方式。

修复
- 改善部分分辨率和缩放比例下，面板与弹窗文字显示不清晰的问题。
- 修复紧凑栏时间位置略微偏高的问题。
- 修复网易云音乐切歌提示延迟、浏览器切歌时闪现其他播放器内容，以及部分歌曲缺少歌词的问题。
- 移除套餐标签，以及 Token 用量明细表中应用和模型名称上多余的悬停提示。
