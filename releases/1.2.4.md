New

AI usage
- Claude supports Team plans.
- Pi is available as a usage app.
- Sources billed by API usage can have a target balance, 100 by default (Settings > Quotas and usage > Apps, expand the app's row). With a target balance, the quota ring, progress bar, warning colors and alerts apply.
- The quota rings when collapsed can show each app's first letter inside the ring: turn on "Letter in the rings" in Settings > Collapsed view > Content > Quota rings. It is off by default.

Music
- KuGou Music is supported.
- NetEase Cloud Music has a new "Always enable full control" switch (Settings > Players > NetEase Cloud Music), so you no longer need to click "Enable full control" each time.
- The equalizer has a new "Spectrum" mode: choose "Flow" or "Spectrum" in Settings > Style > General > Equalizer mode.
- The equalizer's color can be set on its own.
- Music can hide the cover (Settings > Style > When collapsed / When expanded > Show cover).
- New "Hide while paused" option (Settings > Style > When collapsed): while music is paused, the middle text, the cover or both can be hidden, and they come back when playback resumes.
- When collapsed, lyrics are shown when a song has them, and the song title is shown for instrumentals.

System monitor
- New frame rate reading. For the expanded view, turn on "Show the frame rate" in Settings > Display and readings > When expanded; for the collapsed view, choose "Frame rate" among the readings in Settings > Display and readings > When collapsed.
- New "Enhanced sensors" page (Settings > Enhanced sensors): after installing the PawnIO driver and turning on the sensor service, the CPU temperature and power are read directly from the processor, for computers where these two readings are missing.
- When enhanced sensors are off and HWiNFO or LibreHardwareMonitor is running, BrimDeck also reads the CPU temperature and power from it.

Collapsed and expanded views
- The notch and the indicator can be placed at the top, bottom, left or right edge of the screen (Settings > Collapsed view > Size and position > Edge).
- The notch, the capsule and the indicator can be placed inside the taskbar.
- After double-clicking a resize handle, you can drag the collapsed panel to a new position (Settings > Collapsed view > Shortcuts).
- New "Expand at" setting (Settings > Expanded view > General): when the notch or the capsule is wider than the expanded panel, a panel opened by hovering used to always center on the pointer; it now opens from the middle of the notch or capsule by default, and you can choose "Pointer" to get the old behavior. When the notch or the capsule is not wider than the expanded panel, nothing changes.
- The clock has a new "Show seconds" switch (Settings > Collapsed view > Content > Clock), off by default.

Windows and Settings
- New "Also check windows behind" switch (Settings > General > Window behavior), on by default: when a window behind the one you are using is maximized or full screen, the matching window rule applies.
- New "Keep on top" switch and "Raise now" button (Settings > General > Compatibility): bring the panel back to the top when another always-on-top window covers it.
- New "Show tray icon" switch (Settings > General > Startup and resources). When it is off, there is no tray icon; opening BrimDeck again while it runs shows the hidden panel and opens Settings.
- New "Exit BrimDeck" button on the General page of Settings.
- New "What's new" window that lists the release notes of each version, also available offline (Settings > BrimDeck > Project, next to the current version).
- Settings can be used with the keyboard and screen readers; the expanded panel can be used with screen readers.

Improvements
- The equalizer settings are now together in Settings > Style > General.
- Before the AI usage page has readings, it shows placeholders; if reading fails, it shows the reason and a "Sync now" button.
- CPU usage is now calculated from processor busy time, matching Task Manager in Windows 11 24H2 and later.
- The total GPU usage comes from the graphics driver first (NVIDIA, AMD, Intel); where the driver gives none, it is calculated the way Task Manager does.
- Improved where the CPU and GPU temperature and power are read from, with support for more graphics cards; temperature tooltips show where the reading comes from.
- "Free memory when idle" is on by default for new installs (Settings > General > Startup and resources); existing settings are kept.
- Lower memory and CPU use.
- Improved some animations and how some parts look.
- Improved the layout and descriptions of Settings.

Fixes
- The "Full" preset of System monitor when collapsed now shows every item with every figure.
- Fixed text and panel edges shaking at the end of the expand animation; the bounce at the end is also softer.
- Fixed the equalizer not moving and the player name being wrong for some players.
- Fixed Apple Music showing another song's lyrics in some cases.
- Lower resource use when reading the shuffle, repeat and progress bar of Apple Music.
- Fixed word-by-word time marks (such as <01:23.45>) showing in lyrics.
- Fixed power figures above 100 W in System monitor not being shown in full.
- Fixed the GPU column being cut off in the power tooltip of System monitor when the graphics card's name is long.
- Fixed the main CPU graph of System monitor not filling the available width on CPUs with few cores.
- Fixed the CPU area on the right being wider with the GPU shown large than the GPU area with the CPU shown large in System monitor.
- Fixed BrimDeck windows not being captured by screen recording or screenshot tools that use Windows Graphics Capture.
- Fixed the scroll bar thumb showing only its upper half when the music page's content area is short.
- Fixed number boxes in the Settings window not taking input when their empty area was clicked.

新功能

AI 用量
- Claude 支持 Team 订阅。
- 统计应用支持 Pi。
- 按 API 计费的来源可设置目标余额，默认为 100（设置 > 配额与统计 > 应用，展开对应的应用行后填写）。设置后，配额环、进度条、预警颜色与提醒随之生效。
- 收起时的配额环可以在环内显示应用的首字母：在“设置 > 收起外观 > 显示内容 > 配额环”中开启“环内显示首字母”，默认关闭。

音乐
- 支持酷狗音乐。
- 网易云音乐新增“始终启用完整控制”开关（设置 > 播放器 > 网易云音乐），不需要每次都点击“启用完整控制”按钮。
- 律动条新增“频谱”方式：在“设置 > 样式 > 通用 > 律动方式”中可选择“流动”或“频谱”。
- 律动条支持单独设置颜色。
- 音乐可选不显示封面（设置 > 样式 > 收起时 / 展开时 > 显示封面）。
- 收起时新增“暂停时隐藏”（设置 > 样式 > 收起时）：音乐暂停时，可以隐藏中间文字、封面或两者，恢复播放后重新显示。
- 收起时支持有歌词时显示歌词，纯音乐时显示歌名。

系统监控
- 新增帧率读数：展开时在“设置 > 显示与读数 > 展开时”打开“显示帧率”；收起时在“设置 > 显示与读数 > 收起时”的读数中选择“帧率”。
- 新增“增强传感器”设置页（设置 > 增强传感器）：安装 PawnIO 驱动并启用传感器服务后，可以直接从处理器读取 CPU 温度和功耗，适用于读不到这两项的电脑。
- 未启用增强传感器时，如果正在运行 HWiNFO 或 LibreHardwareMonitor，BrimDeck 也会从中读取 CPU 温度和功耗。

收起与展开
- 刘海和指示条可贴靠屏幕的顶部、底部、左侧或右侧（设置 > 收起外观 > 尺寸与位置 > 贴靠位置）。
- 刘海、胶囊、指示条支持放置在任务栏内。
- 双击调整把手后，可直接拖动收起面板改变位置（设置 > 收起外观 > 快捷操作）。
- 新增“展开位置”设置（设置 > 展开外观 > 通用）：刘海或胶囊比展开面板更宽时，悬停展开的面板以前总是以鼠标所在位置为中心展开，现在默认从刘海或胶囊的正中间展开，也可以选择“跟随鼠标”恢复以前的方式。刘海或胶囊不比展开面板宽时，展开位置不受影响。
- 时间新增“显示秒数”开关（设置 > 收起外观 > 显示内容 > 时间），默认关闭。

窗口与设置
- 新增“同时检测后方窗口”开关（设置 > 常规 > 窗口行为），默认开启：开启后，正在使用的窗口后方有窗口最大化或全屏时，也按对应的窗口规则处理。
- 新增“持续置顶”开关与“立即置顶”按钮（设置 > 常规 > 兼容性）：面板被其他置顶窗口遮挡时，可恢复到最上层。
- 新增“显示托盘图标”开关（设置 > 常规 > 启动与资源占用）。关闭后不显示托盘图标；BrimDeck 运行时再次打开 BrimDeck，会显示隐藏的面板并打开设置。
- 设置“常规”页新增“退出 BrimDeck”按钮。
- 新增“更新内容”窗口，按版本列出历次更新说明，离线也能查看（设置 > BrimDeck > 项目信息，当前版本号旁）。
- 设置页支持键盘与读屏操作；展开面板支持读屏操作。

改进
- 律动条的设置集中到“设置 > 样式 > 通用”。
- AI 用量页还没有读数时，先显示占位内容；读取失败时显示原因，并提供“立即同步”按钮。
- CPU 占用率改为按处理器忙碌时间计算，与 Windows 11 24H2 起的任务管理器一致。
- GPU 总利用率优先使用显卡驱动的读数（NVIDIA、AMD、Intel），读不到时再按任务管理器的方式计算。
- 优化 CPU、GPU 温度与功耗的读取来源，支持更多型号的显卡；温度提示会标明读数来源。
- “空闲时释放内存”在新安装时默认开启（设置 > 常规 > 启动与资源占用），已有设置保持不变。
- 优化内存与 CPU 占用。
- 优化部分动画与显示效果。
- 优化设置页的布局与说明。

修复
- 系统监控收起时的“完整”预设改为显示全部监控项和全部数值。
- 修复展开动画结束时文字与面板边缘抖动的问题，展开末尾的回弹也更柔和。
- 修复部分播放器的律动条不跳动、播放器名称显示不正确的问题。
- 修复 Apple Music 在部分情况下显示其他歌曲歌词的问题。
- 降低读取 Apple Music 随机播放、循环和进度条时的资源占用。
- 修复歌词中显示逐字时间标记（如 <01:23.45>）的问题。
- 修复系统监控的功率超过 100 W 时数字显示不全的问题。
- 修复系统监控功耗提示中，显卡名称较长时 GPU 一列被截断的问题。
- 修复 CPU 核心较少时，系统监控的 CPU 主图没有占满可用宽度的问题。
- 修复系统监控以 GPU 为主时，右侧 CPU 区域比以 CPU 为主时的 GPU 区域更宽的问题。
- 修复 BrimDeck 窗口无法被使用 Windows Graphics Capture 的录屏或截图工具捕获的问题。
- 修复音乐页面内容区较短时，面板滚动条的滑块只显示上半截的问题。
- 修复设置窗口中点击数值框空白处无法输入的问题。
