New
- The quota rings when collapsed can show each app's first letter inside the ring: turn on "Letter in the rings" in Settings > Collapsed view > Content > Quota rings. It is off by default.
- New "Hide while paused" option (Settings > Style > When collapsed): while music is paused, the middle text, the cover or both can be hidden, and they come back when playback resumes.
- When the middle text is "Lyrics", a new "Show the title for instrumentals" switch shows the song title for a song recognized as instrumental, instead of only a "♪" mark.

Improvements
- CPU usage is now calculated from processor busy time, matching Task Manager in Windows 11 24H2 and later.
- On the expanded music page, the song title stays still when it fits and scrolls when it does not.
- "Keep on top" now checks whether the panel is covered as soon as window order changes, a window appears or the foreground window changes, so the panel returns to the top sooner.
- Improved how the network speed is shown in the collapsed row.
- Improved how some parts of the Settings window look.
- Lower memory and CPU use.

Fixes
- Lower resource use when reading the shuffle, repeat and progress bar of Apple Music; BrimDeck no longer looks for the Apple Music window over and over while Apple Music is not open.
- Fixed number boxes in the Settings window not taking input when their empty area was clicked.
- Fixed word-by-word time marks (such as <01:23.45>) showing in lyrics.

新功能
- 收起时的配额环可以在环内显示应用的首字母：在“设置 > 收起外观 > 显示内容 > 配额环”中开启“环内显示首字母”，默认关闭。
- 收起时新增“暂停时隐藏”（设置 > 样式 > 收起时）：音乐暂停时，可以隐藏中间文字、封面或两者，恢复播放后重新显示。
- 收起时中间文字为“歌词”时，新增“纯音乐时显示歌名”开关：识别为纯音乐时显示歌名，而不是只显示音符“♪”。

改进
- CPU 占用率改为按处理器忙碌时间计算，与 Windows 11 24H2 起的任务管理器一致。
- 展开的音乐页中，歌名放得下时保持静止，放不下时循环滚动。
- “持续置顶”在窗口层级变化、窗口显示和前台切换时立即检查是否被遮挡，恢复置顶更及时。
- 优化收起行的网速显示。
- 优化设置窗口部分内容的显示效果。
- 降低内存与 CPU 占用。

修复
- 降低读取 Apple Music 随机播放、循环和进度条时的资源占用；Apple Music 未打开时，不再频繁查找它的窗口。
- 修复设置窗口中点击数值框空白处无法输入的问题。
- 修复歌词中显示逐字时间标记（如 <01:23.45>）的问题。
