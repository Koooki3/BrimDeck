New
- New "Clipboard sync" page (test feature) (Settings > Shelf > Clipboard sync), with Local network, WeType and Doubao IME.
- New window rule "When a window overlaps BrimDeck" (Settings > General > Window behavior): BrimDeck can hide by itself when a window is moved onto the collapsed BrimDeck.
- New layout options for the expanded music page (Settings > Style > When expanded > Layout), with several layouts for showing or hiding the lyrics and the cover.
- New "Follow Windows" switch for panel themes (Settings > Panel theme > Current theme), for themes with a night look: the night look is shown while Windows uses dark mode, and the day look while it uses light mode.
- Theme files can also define a dusk look, shown for a while before night starts.
- New "Same side" option for the stacked shelf layout (Settings > Shelf > Page layout > Stack position), so switching is easier.
- Files can be dragged out of the file transfer with the right mouse button. The "Drag files out" setting now has two options: "Left copies, right moves" (default) and "Left moves, right copies".
- New "Remove from transfer after a move to a copy-only target" switch for the file transfer, off by default.
- Phone battery levels are read first from the battery level and charging state that Windows "Phone Link" keeps on this PC; Bluetooth is used only when Phone Link is not running or its data is out of date.
- Battery levels are supported for NuPhy wireless keyboards, WOBKEY and PMO wireless keyboards (such as Rainy75 V2, Rainy98, Zen 65, Aurora80 and Wave75), the Metaphyuni Metapanda P1, and the Razer BlackShark V2 HyperSpeed, BlackShark V3 X HyperSpeed, BlackShark V3 Pro, Kraken V4 Pro and Kraken Kitty V3 Pro wireless headsets. More WLmouse models are supported.
- AI quota reading supports the new version of ZCode.

Improvements
- Clicking outside the panel collapses it immediately, without waiting for the collapse delay.
- Some messages are improved.
- With "Lyric area follows the line length" on, the lyrics stay centered where they are and the content on both sides moves together. The lyric and title areas can grow up to the width of the screen.
- With Hyper-V on, CPU usage includes the load of WSL2 and virtual machines.
- Battery levels are read more reliably through receivers shared by brands such as AULA.
- Battery levels of Razer devices are rounded the same way as in Razer's own software.

Fixes
- Fixed the tray icon not appearing, or the panel not expanding, after one step failed during startup. Adding the tray icon is retried if it fails.
- Fixed BrimDeck exiting when audio capture failed.
- Fixed the panel not collapsing when you click outside it while the search box has focus.
- Fixed battery levels in the collapsed row not coming back after a Bluetooth device wakes up and reconnects.
- Fixed a device's name, color, show and read switches and order being lost after the device was recognized again.
- Fixed some Bluetooth devices stopping the device list from being read.
- Fixed drop-down lists in the settings window showing twice side by side when Windows is set to right-aligned menus.
- Fixed the content shifting by 1 pixel at the end of the width animation of "Lyric area follows the line length".
- Fixed the CPU core tooltip.

新功能
- 新增“剪贴板同步”设置页（测试功能）（设置 > 中转站 > 剪贴板同步），包含局域网、微信输入法、豆包输入法。
- 新增窗口规则“有窗口与 BrimDeck 重叠时”（设置 > 常规 > 窗口行为）：有窗口移到收起的 BrimDeck 所在位置时，可以自动隐藏。
- 音乐页新增展开时的布局选项（设置 > 样式 > 展开时 > 布局），包括显示/不显示歌词和封面的多种布局。
- 面板主题新增“跟随系统深浅”开关（设置 > 面板主题 > 当前主题），适用于带夜间外观的主题：Windows 使用深色模式时显示夜间外观，浅色模式时显示白天外观。
- 主题文件还可以写一个黄昏外观，在夜晚开始前的一段时间内显示。
- 中转站的叠放布局新增“同侧堆叠”（设置 > 中转站 > 页面布局 > 堆叠位置），切换更顺手。
- 文件中转支持用右键拖出文件。“拖出文件”设置改为两个选项：“左键复制，右键移动”（默认）和“左键移动，右键复制”。
- 文件中转新增“移动到不支持移动的目标后，从中转站移除”开关，默认关闭。
- 手机电量优先读取 Windows“手机连接”保存在本机的电量与充电状态；手机连接未运行或数据过期时，才改用蓝牙读取。
- 外设电量新增支持 NuPhy 无线键盘，WOBKEY 与 PMO 无线键盘（如 Rainy75 V2、Rainy98、Zen 65、Aurora80、Wave75），玄派玄熊猫 P1，以及雷蛇 BlackShark V2 HyperSpeed、BlackShark V3 X HyperSpeed、BlackShark V3 Pro、Kraken V4 Pro、Kraken Kitty V3 Pro 无线耳机；WLmouse 支持更多型号。
- AI 配额读取支持新版 ZCode。

改进
- 点击面板以外的地方时，面板立即收起，不再等待收起延迟。
- 部分提示内容优化。
- “歌词区域随歌词长度变化”开启时，歌词保持在原位置的中间，两侧的内容同时移动；歌词与歌名区域最宽可以达到屏幕宽度。
- 开启 Hyper-V 时，CPU 占用率包含 WSL2 与虚拟机的负载。
- 狼蛛等品牌共用接收器的电量读取更稳定。
- 雷蛇设备的电量按雷蛇官方软件的方式取整。

修复
- 修复启动过程中某一步出错后，托盘图标不出现或面板无法展开的问题。托盘图标添加失败时会自动重试。
- 修复音频采集出错时 BrimDeck 退出的问题。
- 修复搜索框有焦点时，点击面板外部后面板不收起的问题。
- 修复蓝牙设备休眠后重新连接时，收起行的电量不恢复的问题。
- 修复设备重新识别后，已设置的名称、颜色、显示与读取开关和顺序丢失的问题。
- 修复部分蓝牙设备导致设备列表读取中断的问题。
- 修复 Windows 设为右对齐菜单时，设置窗口中的下拉列表并排显示两份的问题。
- 修复“歌词区域随歌词长度变化”的宽度动画结束时，内容整体偏移 1 像素的问题。
- 修正 CPU 核心的悬停提示。
