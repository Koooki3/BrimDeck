Fixes
- [Important] Fixed some PCs freezing while hardware readings were taken. If the PC freezes during a reading, BrimDeck stops that reading the next time it starts. Stopped readings are listed under System monitor > When expanded in Settings, where each can be turned on again.
- Fixed PCs that use Intel Rapid Storage Technology (RAID mode) freezing when drive temperatures were read. These drives no longer report temperature; their space is still shown.
- Fixed CPU usage staying high after opening token usage details in some cases, which also kept settings from being saved.
- Fixed some Microsoft Store versions of the Claude desktop app not being found and showing as not connected.

New
- New option to receive beta updates: turn on "Receive beta updates" in Settings > About. Betas include new features early but may be less stable. If you run into a problem, please use "Send feedback" at the bottom of the About page. (If your PC freezes or you hit another serious problem, we would be grateful if you could report it. PCs use a wide range of hardware, and we can only test on the few devices we have, so your report helps us find and fix the problem sooner.)
- System monitor shows system power and battery charge.
- In the collapsed view, the position of the equalizer and the clock can be changed.
- The equalizer's length and color can be customized.
- The equalizer can be set to always show; while no music plays, it moves with system sound.
- The process details card has an Open button that brings the app's most recent window to the front.

Improvements
- "Show temperatures" in System monitor is now off by default.
- NVIDIA graphics power is read only while power is shown and the card is busy, so an idle discrete graphics card is not woken up.
- Colors for drives, system power and battery can be customized.
- Improved how some parts of the expanded System monitor page look.

修复
- [重要] 修复部分电脑在读取硬件参数时卡死的问题。如果读取时电脑卡死，BrimDeck 下次启动时会停止读取这一项。已停止的项目列在设置“系统监控 > 展开时”中，可以逐项重新开启。
- 修复使用 Intel 快速存储技术（RAID 模式）的电脑在读取硬盘温度时整机卡死的问题。这类硬盘不再读取温度，空间占用照常显示。
- 修复部分情况下打开 Token 用量详情后 CPU 占用一直偏高、设置无法保存的问题。
- 修复部分 Microsoft Store 版 Claude 桌面应用未被识别、显示为“未连接”的问题。

新功能
- 新增接收测试版更新功能，可在“设置 > 关于”中打开“接收测试版更新”开关。测试版可提前体验新功能，但可能不够稳定。遇到问题时，欢迎在“关于”页最下方点击“提交反馈”。（如果遇到卡死等严重问题，恳请您反馈：电脑硬件种类很多，我们手上的设备有限，无法在每种硬件上都测试到，您的反馈能帮助我们尽快找到并修复问题。）
- 系统监控新增整机功耗、电量监控。
- 收起状态支持调节律动条和时间的显示位置。
- 律动条支持自定义长度、自定义颜色。
- 律动条可选始终显示，没有音乐播放也会随系统声音跳动。
- 进程详情卡片新增“打开”按钮，点击后把该应用最近使用的窗口切到前台。

改进
- 系统监控的“显示温度”改为默认关闭。
- 只在显示功耗且显卡有负载时读取 NVIDIA 显卡功耗，不会唤醒休眠的独立显卡。
- 硬盘、整机功耗和本机电池支持自定义配色。
- 系统监控展开页部分显示效果优化。
