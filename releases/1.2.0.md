New
- Panel themes: 7 new themes, including Light, One Dark Pro, Night Owl and Cyberpunk: Edgerunners, plus custom themes.
- New "System monitor" page (adapted from ftop): shows CPU, GPU, memory, network speed and more in real time.
- Every expanded page can be resized by dragging its edges. The notch, the capsule and the indicator bar can be resized by dragging their ends.
- Full-screen detection can have exception apps: when one of them is full screen or maximized, the panel is not affected.
- Option to free memory when the panel has been collapsed and idle (off by default).
- Usage of Claude Code and Codex in WSL can be counted (off by default).

Improvements
- The content shown in the notch and the capsule can be reordered.
- The notch and the capsule can fit their width to their content.
- The notch and the capsule can be as wide as the screen; when one is wider than the panel, hovering it opens the panel under the pointer.
- Improved animations in many places.
- Improved the look of the panel and the settings in many places.
- Support for the new version of the Claude desktop app, and an improved cache for Claude quota readings.
- Lower memory use when reading session logs; very long lines no longer make memory use keep growing.
- New API, Sub2API and custom sources connect over HTTPS only by default; HTTP can be turned on by hand.
- Lyrics lookups no longer follow redirects to other sites or to HTTP, and the size of a response is limited, so an abnormal response cannot use up memory.
- When installed to a custom folder outside Program Files and the user folder, Setup restricts who can change that folder, so other accounts on this PC cannot replace the program files.
- Less stutter when changing settings or switching songs.

Fixes
- Fixed a large block of the indicator bar's color flashing when hovering the indicator bar to expand the panel.
- Fixed the Claude plan showing as Pro after an upgrade to Max: the plan now comes from the Claude account first, then the local account record, and only last from the sign-in token; it is also read when the usage service is rate-limited.
- The message shown when NetEase Cloud Music full control fails to connect is now accurate.

新功能
- 新增面板主题功能，增加浅色、One Dark Pro、Night Owl、赛博朋克等 7 个主题，并支持自定义主题。
- 新增“系统监控”功能（参考 ftop 改编）：可实时显示 CPU、GPU、内存、网速等内容。
- 展开面板的各页都可拖动边缘调整大小。刘海、胶囊与指示条可拖动两端调整宽度。
- 全屏检测可添加例外应用，这些应用全屏或最大化时面板不受影响。
- 可选在面板收起空闲时释放内存（默认关闭）。
- 支持统计 WSL 中 Claude Code 与 Codex 的用量，该功能默认关闭。

改进
- 刘海和胶囊的显示内容可排序。
- 刘海和胶囊新增自适应宽度功能。
- 刘海和胶囊的最大宽度提高到与屏幕同宽；刘海或胶囊比面板宽时，悬停展开的面板出现在鼠标所在位置。
- 优化多处动画效果。
- 优化多处面板与设置的显示效果。
- 适配 Claude 桌面版新版本，并优化 Claude 额度读取缓存功能。
- 降低读取会话记录时的内存占用，特别长的行不再导致内存持续增长。
- New API、Sub2API 与自定义来源默认只支持通过 HTTPS 连接，可手动开启 HTTP。
- 歌词查询不再跳转到其他网站或 HTTP 地址，并限制返回内容的大小，避免异常响应占用大量内存。
- 安装到 Program Files 与用户目录以外的自定义文件夹时，限制该文件夹的修改权限，防止本机其他账户替换程序文件。
- 减少修改设置、切换歌曲时的界面卡顿。

修复
- 修复悬停指示条展开面板时，闪现一大块指示条颜色的问题。
- 修复升级到 Max 后 Claude 订阅仍显示为 Pro 的问题：订阅名改为优先取自 Claude 账户，其次是本地账户记录，最后才用登录令牌；用量接口被限流时也会读取。
- 网易云音乐完整控制连接失败时，提示更准确。
