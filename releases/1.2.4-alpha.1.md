New
- Claude supports Team plans.
- Pi is available as a usage app (Settings > Quotas and usage > Apps, choose Pi under "Usage app").
- System monitor shows a frame rate: the frames per second drawn by the app in front. For the expanded view, turn on "Show the frame rate" in Settings > Display and readings > When expanded; for the collapsed view, choose "Frame rate" among the readings in Settings > Display and readings > When collapsed.
- KuGou Music gets full control and KuGou lyrics. To use full control, turn on "Always enable full control" in Settings > Players > KuGou Music.
- NetEase Cloud Music has a new "Always enable full control" switch (Settings > Players > NetEase Cloud Music), so you no longer need to click "Enable full control" each time.
- The notch and the indicator can be placed at the top, bottom, left or right edge of the screen (Settings > Collapsed view > Size and position > Edge).
- The notch, the capsule and the indicator can be placed inside the taskbar: for the notch and the indicator, choose "Screen edge" under "Hang from" in Settings > Collapsed view > Size and position; for the capsule, move "Vertical offset" in the same place to the bottom.
- New "Double-click a resize handle" setting (Settings > Collapsed view > Shortcuts): after double-clicking a resize handle, you can drag the collapsed panel to a new position.
- New "Expand at" setting (Settings > Expanded view > General): when expanded by hovering, the panel now opens from the middle of the collapsed panel by default; you can choose "Pointer" instead.
- New "Also check windows behind" switch (Settings > General > Window behavior), on by default: when a window behind the one you are using is maximized or full screen, the matching window rule applies.
- New "Keep on top" switch and "Raise now" button (Settings > General > Compatibility): bring the panel back to the top when another always-on-top window covers it.
- The clock has a new "Show seconds" switch (Settings > Collapsed view > Content > Clock), off by default.
- Sources billed by API usage can have a target balance, 100 by default (Settings > Quotas and usage > Apps, expand the app's row). With a target balance, the quota ring, progress bar, warning colors and alerts apply.
- Music can hide the cover (Settings > Style > When collapsed / When expanded > Show cover).
- The equalizer and the current lyric on the music page can have separate colors (Settings > Style > When expanded).
- New "What's new" window that lists the release notes of each version, also available offline (Settings > BrimDeck > Project, next to the current version).
- Settings can be used with the keyboard and screen readers; the expanded panel can be used with screen readers.

Improvements
- Before the AI usage page has readings, it shows placeholders in the same layout and fills them in place when readings arrive; if reading fails, it shows the reason and a "Sync now" button.
- Improved some animations.
- Improved some descriptions in Settings.
- Network speeds of 10 or more in System monitor are shown without decimals, so the network readings take less room.

Fixes
- Fixed text and panel edges shaking at the end of the expand animation; the bounce at the end is also softer.
- Fixed the equalizer not moving and the player name being wrong for some players.
- Fixed power figures above 100 W in System monitor not being shown in full.
- Fixed Apple Music showing another song's lyrics in some cases.
- Fixed BrimDeck windows not being captured by screen recording or screenshot tools that use Windows Graphics Capture.
- Fixed the scroll bar thumb showing only its upper half when the music page's content area is short.
- Fixed the CPU area on the right being wider with the GPU shown large than the GPU area with the CPU shown large in System monitor.

新功能
- Claude 支持 Team 订阅。
- 统计应用支持 Pi（设置 > 配额与统计 > 应用，在“统计应用”中选择 Pi）。
- 系统监控新增帧率读数，显示前台程序每秒绘制的帧数。展开时在“设置 > 显示与读数 > 展开时”打开“显示帧率”；收起时在“设置 > 显示与读数 > 收起时”的读数中选择“帧率”。
- 酷狗音乐新增完整控制与酷狗歌词。完整控制在“设置 > 播放器 > 酷狗音乐”中打开“始终启用完整控制”。
- 网易云音乐新增“始终启用完整控制”开关（设置 > 播放器 > 网易云音乐），不需要每次都点击“启用完整控制”按钮。
- 刘海和指示条可贴靠屏幕的顶部、底部、左侧或右侧（设置 > 收起外观 > 尺寸与位置 > 贴靠位置）。
- 刘海、胶囊、指示条支持放置在任务栏内：刘海与指示条在“设置 > 收起外观 > 尺寸与位置”的“贴在”中选择“屏幕边缘”；胶囊把同一位置的“垂直偏移”调到底部。
- 新增“双击调整把手”设置（设置 > 收起外观 > 快捷操作），双击调整把手后，可直接拖动收起面板改变位置。
- 新增“展开位置”设置（设置 > 展开外观 > 通用）：悬停展开时面板默认从收起面板的正中间展开，也可选择“跟随鼠标”。
- 新增“同时检测后方窗口”开关（设置 > 常规 > 窗口行为），默认开启：开启后，正在使用的窗口后方有窗口最大化或全屏时，也按对应的窗口规则处理。
- 新增“持续置顶”开关与“立即置顶”按钮（设置 > 常规 > 兼容性）：面板被其他置顶窗口遮挡时，可恢复到最上层。
- 时间新增“显示秒数”开关（设置 > 收起外观 > 显示内容 > 时间），默认关闭。
- 按 API 计费的来源可设置目标余额，默认为 100（设置 > 配额与统计 > 应用，展开对应的应用行后填写）。设置后，配额环、进度条、预警颜色与提醒随之生效。
- 音乐可选不显示封面（设置 > 样式 > 收起时 / 展开时 > 显示封面）。
- 音乐页的律动条与当前歌词可分别设置颜色（设置 > 样式 > 展开时）。
- 新增“更新内容”窗口，按版本列出历次更新说明，离线也能查看（设置 > BrimDeck > 项目信息，当前版本号旁）。
- 设置页支持键盘与读屏操作；展开面板支持读屏操作。

改进
- AI 用量页还没有读数时，先显示与正式版式相同的占位内容，读数到达后在原位置填入；读取失败时显示原因，并提供“立即同步”按钮。
- 部分动画效果优化。
- 部分设置菜单说明内容优化。
- 系统监控的网速在 10 以上时不显示小数，网络读数更紧凑。

修复
- 修复展开动画结束时文字与面板边缘抖动的问题，展开末尾的回弹也更柔和。
- 修复部分播放器的律动条不跳动、播放器名称显示不正确的问题。
- 修复系统监控的功率超过 100 W 时数字显示不全的问题。
- 修复 Apple Music 在部分情况下显示其他歌曲歌词的问题。
- 修复 BrimDeck 窗口无法被使用 Windows Graphics Capture 的录屏或截图工具捕获的问题。
- 修复音乐页面内容区较短时，面板滚动条的滑块只显示上半截的问题。
- 修复系统监控以 GPU 为主时，右侧 CPU 区域比以 CPU 为主时的 GPU 区域更宽的问题。
