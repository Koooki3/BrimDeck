New
- Kimi Code as a quota and statistics source.
- Kimi Code API source.
- Full-screen exceptions become app rules: for each app, choose what the panel does in each kind of full screen.
- Custom themes can be edited directly on the Panel Theme page in Settings.
- While the panel is expanded, the mouse wheel can switch pages or change the volume.
- Limited support for Windows 10 (version 2004 and later). The settings window has a square frame without the rounded corners and border theme of Windows 11; the music visualizer cannot capture the player's own audio and uses the volume peak reported by the system instead, so it may follow the music less closely.

Improvements
- Improved some animations in Settings.
- Improved the layout of the System monitor settings page.
- Improved the layout and icons of the expanded System monitor page.
- Dracula and Night Owl now use the minimal clock in the theme's color by default.
- Fewer unnecessary tooltips in the price list.
- Checked music sources show the pin on hover.
- Improved switching the process rows in Settings.
- Performance improvements.

Fixes
- Fixed the page jumping when the song changes.
- Fixed the panel sometimes staying open in preview after adjusting its look in Settings and clicking elsewhere.
- Fixed the monitor dial letters sitting off the centre of their rings at fractional display scaling.

新功能
- 新增 Kimi Code 额度与统计来源。
- 新增 Kimi Code API 来源。
- 全屏例外升级为应用程序规则，可按应用分别设置各种全屏情况下的面板行为。
- 支持在设置中的面板主题页直接编辑自定义主题。
- 面板展开时，可通过鼠标滚轮切换页面或调节音量。
- 有限支持 Windows 10（2004 及以上版本）。设置窗口为直角外框，不带 Windows 11 的圆角和边框主题；音乐律动无法单独采集播放器的音频，改为使用系统提供的音量峰值，跟随效果可能不够精确。

改进
- 设置页部分动画优化。
- 系统监控设置页面排版优化。
- 系统监控展开面板排版优化、图标优化。
- Dracula 与 Night Owl 主题改为默认使用主题色的简洁时钟。
- 减少价格表中不必要的悬浮提示。
- 已勾选的音乐源在鼠标悬停时显示置顶图标。
- 优化在设置页面切换进程行的体验。
- 性能优化。

修复
- 修复切歌时页面跳变的问题。
- 修复部分情况下在设置中调整外观后，点击其他地方，面板仍停留在预览状态没有自动收起的问题。
- 修复在显示器非整数缩放下，监控表盘中的字母偏离圆环中心的问题。
