New
- Support for the Apple Music desktop app.
- OpenCode as a quota and statistics source, and OpenCode Go and OpenRouter as quota sources that take a key you enter.
- Quota sources can have off-peak hours.
- System monitor shows drive usage, and CPU, GPU and SSD temperatures.
- The order of the expanded panel's pages can be changed by dragging in Settings.
- New Smoothing option for the collapsed system readings: Off, 10 fps or 30 fps.
- New Scale setting, 100% or 150%, for high-resolution screens.
- The panel can be resized with a shortcut.
- New themes: Island Holiday, Island Holiday 2 and Pixel Blocks. The Island Holiday themes change gradually between a day look and a night look by local time.
- New Pixel and Rounded clock styles.
- A portable zip is available; the portable version also updates from within the app.
- When a Windows contrast theme is on, the panel, the settings window and the tray menu use the system colors.

Improvements
- Dragging a window to the top of the screen for Snap layouts no longer expands the panel.
- New NetEase Cloud Music option to enable full control when it starts.
- System monitor supports more than one graphics card: choose which one shows in Settings, or click the GPU reading to switch.
- Higher contrast for secondary text, warning and critical colors, and scroll bars in every theme, so they are easier to read.
- The collapsed readings and quota rings always show whole items, adjusted once you finish changing the width.
- Cost estimates prefer the prices of the model maker's own channel.
- When the settings file cannot be read, a copy of the original file is kept before the default settings are used.
- Switching themes fades the panel to the new look.
- Some animations improved.
- Performance improvements in some cases.

Fixes
- Fixed Cursor token details showing no usage when there are many records.
- Fixed QQ Music lyrics not loading.
- Fixed the previous panel flashing briefly when the expand shortcut opens the panel while it is hidden.
- Fixed the scrolling collapsed readings and quota rings stopping with an item partly shown.
- Fixed a tooltip staying on screen after switching pages.
- Fixed large DSH session files affecting usage statistics.
- Fixed Claude quota requests continuing after being rate limited; requests now pause for the time the server asks.

新功能
- 支持 Apple Music 桌面版。
- 新增 OpenCode 额度与统计来源，以及需要手动填写密钥的 OpenCode Go、OpenRouter 额度来源。
- 配额来源可设置低峰时间。
- 系统监控新增硬盘占用，以及 CPU、GPU 和固态硬盘温度。
- 展开面板的页面顺序可以在设置中拖动调整。
- 收起时的系统读数新增“平滑过渡”选项，可选不平滑、10 帧或 30 帧。
- 新增“缩放”设置，可选 100% 或 150%，用于适配高分辨率屏幕。
- 可通过快捷键调整面板大小。
- 新增主题“海岛假日”“海岛假日 2”和“像素方块”。海岛假日主题按本地时间在白天和夜间外观之间渐变切换。
- 时间新增“像素”和“圆润”两种样式。
- 提供免安装版压缩包，免安装版同样支持应用内更新。
- Windows 开启对比度主题时，面板、设置窗口和托盘菜单改用系统颜色。

改进
- 把窗口拖到屏幕顶部使用贴靠布局时，面板不再随之展开。
- 网易云音乐新增“启动后自动启用完整控制”选项。
- 系统监控支持多块显卡，可以在设置中选择显示哪一块，也可以点击 GPU 读数切换。
- 提高各主题中辅助文字、预警色、告警色和滚动条的对比度，使其更易看清。
- 收起时的读数和配额环始终显示完整的项。在调整完宽度后自动调整。
- 费用估算优先使用模型厂商官方渠道的单价。
- 设置文件无法读取时，先另存原文件，再使用默认设置。
- 切换主题时，面板以渐变方式过渡。
- 部分动画效果优化。
- 部分情况下的性能优化。

修复
- 修复 Cursor Token 明细太多时显示为无用量的问题。
- 修复 QQ 音乐歌词无法获取的问题。
- 修复隐藏状态下用展开快捷键打开面板时，先闪现上次面板的问题。
- 修复收起时读数和配额环滚动显示，停下时有一部分没有完整显示的问题。
- 修复切换页面后，原页面的提示框仍留在屏幕上的问题。
- 修复 DSH 会话文件过大时影响用量统计读取的问题。
- 修复 Claude 额度被限流后仍持续请求的问题，现在按服务器要求的时间暂停请求。
