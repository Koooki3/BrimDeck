New
- Panel themes: System, Dark and Light, built-in theme extensions (Edgerunners, Dracula, GitHub Dark and Light, Night Owl, One Dark Pro) and custom themes from the themes folder, which can be created, edited and deleted in settings.
- Each panel theme remembers the app, warning and critical colors and the clock style changed under it, and brings them back when you switch back to it.
- New "System monitor" page in the expanded panel, adapted from ftop: CPU usage with its last minute, a column per core (performance and efficiency cores in their own colors, with frequency ticks), the GPU by engine with its memory, memory in use, cached and committed, network speed with its last minute, and the busiest apps, folded by program, sortable by CPU or memory, with a card per app.
- The notch and the capsule can show system readings next to the quota rings and the music: full, brief or chosen readings. They widen to fit.
- New "System monitor" settings page for the monitor page's look and the collapsed readings.
- Every expanded page (AI usage, system monitor, music) can be resized by dragging its sides, bottom edge or bottom corners; the notch, the capsule and the indicator bar by dragging their ends (a double click restores the default). Handles appear near the edges, the edge under the pointer lights in the theme's accent, and the size is shown while dragging.
- Option to free memory when the panel has been collapsed and idle (off by default).
- Usage from WSL: Claude Code and Codex CLI sessions in installed WSL distributions can count toward the token and cost statistics (Settings › AI usage › Quotas and usage, off by default).

Improvements
- One set of soft animations across the app; switching pages fades the old page out and the new one in while the panel changes size.
- Maximizing a window or entering full screen turns the panel into the indicator bar with the same animation as expanding and collapsing, and back again; full-screen rules fade the panel out and in.
- The system monitor's figures move smoothly at the display's refresh rate.
- The AI usage page uses larger type when the panel is tall; the music page centres the title beside the cover when there are no lyrics.
- Lower memory use.
- Settings saving, update checks and cover decoding no longer run on the interface thread.

Fixes
- Fixed a crash when switching panel themes in settings.
- Fixed the panel flickering when a resize started or ended.
- Fixed the Claude plan showing as Pro after an upgrade to Max: the plan now comes from the Claude account, then the local account record, and only last from the sign-in token.
- Fixed the Claude card waiting for sign-in after the Claude desktop app moved its data to Claude-Data; its sign-in and local quota history are found there again.

新功能
- 面板主题：跟随系统、深色、浅色，内置主题扩展（Edgerunners、Dracula、GitHub 深色与浅色、Night Owl、One Dark Pro），以及主题文件夹中的自定义主题，可在设置中新建、编辑与删除。
- 每个面板主题会记住在它下面修改的应用颜色、预警与告警颜色和时间样式，切换回来时恢复。
- 展开面板新增“系统监控”页（参考 ftop 改编）：CPU 占用与最近一分钟走势、每个核心一根柱（性能核与能效核分色、带频率刻度）、按引擎显示的 GPU 与显存、内存（已用、缓存、已提交）、网速与最近一分钟曲线，以及按程序归并、可按 CPU 或内存排序的高占用应用，单击查看详情卡片。
- 刘海和胶囊可在配额环、音乐旁显示系统读数：完整、简洁或自选内容，放不下时自动加宽。
- 新增“系统监控”设置页，设置监控页外观与收起时的读数。
- 展开面板的各页（AI 用量、系统监控、音乐）都可拖动两侧、底边或底角调整大小；刘海、胶囊与指示条可拖动两端调整宽度（双击恢复默认）。靠近边缘时浮现把手，悬停的边缘以主题强调色发光，拖动时显示尺寸。
- 可选在面板收起空闲时释放内存（默认关闭）。
- 同步 WSL 中的用量统计：已安装 WSL 子系统中 Claude Code 与 Codex CLI 的会话可计入 Token 与费用统计（设置 › AI 用量 › 配额与统计，默认关闭）。

改进
- 全局统一一套柔和动效；切换页面时旧页淡出、新页淡入，面板同时变换尺寸。
- 窗口最大化或进入全屏时，面板以与展开/收起相同的动画收为指示条，切回时反向；全屏规则隐藏与重新显示面板时淡出淡入。
- 系统监控的数值按显示器刷新率平滑变化。
- AI 用量页在面板较高时使用更大的字号；音乐页没有歌词时标题在封面旁垂直居中。
- 降低内存占用。
- 设置保存、更新检查与封面解码不再占用界面线程。

修复
- 修复在设置中切换面板主题时崩溃的问题。
- 修复拖拽调整大小开始或结束时面板闪烁的问题。
- 修复升级到 Max 后 Claude 订阅仍显示为 Pro 的问题：订阅名改为优先取自 Claude 账户，其次是本地账户记录，最后才用登录令牌。
- 修复 Claude 桌面版把数据迁到 Claude-Data 后 Claude 卡片一直“等待登录”的问题，现在能在新目录中读到登录与本地额度记录。
