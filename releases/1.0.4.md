New
- Added a color picker to the custom color popup. Drag to choose any color; the preset swatches and hex value stay in sync.
- Clicking the cover on the music page now brings the playing app to the front.
- Update checks now run in the background. Previously, BrimDeck checked for updates only when Settings was opened. It now checks 90 seconds after launch and then every 6 hours. A small blue dot on the settings button shows when a new version is available. Settings adds a switch for automatic checks and an option to skip a version.

Improvements
- Updated default theme colors: ZCode now uses a deep navy blue, DeepSeek Harness a soft DeepSeek blue, and manually configured quota sources a light purple.
- Toolbar buttons at the top of the panel now share the same height and corner radius.
- When space is limited, the date button shows only its icon.

Fixes
- Removed duplicate tooltips in the toolbar and fixed tooltips that stayed on screen.
- Removed the hover background from the sync button.

新功能
- 自定义颜色弹出框新增取色盘，可拖动选择任意颜色，并与预设色块和十六进制值同步。
- 在音乐页点击封面，可将正在播放的应用切换到前台。
- 新增后台检查更新。以前只有打开设置页面时才会检查更新，现在启动 90 秒后会检查一次，之后每 6 小时检查一次。有新版本时，设置按钮右上角会显示蓝色小圆点。设置中新增自动检查开关和“跳过此版本”选项。

改进
- 调整默认主题色：ZCode 改为深海军蓝，DeepSeek Harness 改为柔和的 DeepSeek 蓝，手动填写的配额来源统一为淡紫色。
- 面板顶部工具栏按钮的高度与圆角保持一致。
- 空间不足时，日期按钮只显示图标。

修复
- 移除工具栏中重复的悬浮提示，并修复提示残留的问题。
- 移除同步按钮的悬停背景。
