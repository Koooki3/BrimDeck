# 播放器支持

BrimDeck 的音乐页和收起形态会显示正在播放的歌曲，并提供播放控制。歌名放得下时静止显示，放不下时（律动条越长，留给歌名的位置越窄）自动滚动播放，与收起形态一致；关闭动画后不滚动，鼠标悬停可看到完整歌名。不同播放器能提供的信息和控制不同：

| 播放器 | 显示 | 控制 |
| --- | --- | --- |
| 网易云音乐 | 曲目、封面、进度 | 开启 SMTC 后：播放、暂停、切歌<br>开启完整控制后：还可拖动进度、切换播放模式（随机、列表循环、单曲循环），以及喜欢或取消喜欢当前歌曲 |
| QQ 音乐 | 曲目、进度 | 播放、暂停、切歌、拖动进度 |
| Apple Music | 曲目、封面、进度 | 播放、暂停、切歌<br>开启完整控制后：还可拖动进度、开关随机播放、切换重复模式 |
| 酷狗音乐 | 曲目、封面<br>开启完整控制后：还显示实际进度 | 播放、暂停、切歌 |
| 其他播放器 | 播放器提供给 Windows 系统媒体控制的曲目、封面与进度 | 播放器支持的播放、暂停、切歌、拖动进度 |

"其他播放器"指接入 Windows 系统媒体控制的播放器，即播放时会出现在 Windows 音量浮窗媒体卡片中的播放器。

## 网易云音乐

- **默认**：不需要任何设置，即可显示曲目、封面和进度。此时的进度是估算值。
- **开启 SMTC**：在网易云音乐中打开"设置 › 系统 › 开启 SMTC"，之后可以在 BrimDeck 中播放、暂停和切歌。
- **完整控制**：在音乐页点击"启用完整控制"并确认后，网易云音乐会重新启动。之后可以显示实际进度、拖动进度，以及切换播放模式（随机、列表循环、单曲循环）。网易云音乐已登录并联网时，控制按钮右侧还会显示红心：点击后把当前歌曲加入"我喜欢的音乐"，再点一次取消；在网易云音乐中点红心，BrimDeck 也会同步显示。网易云音乐以普通方式重新启动后，即恢复普通模式。SMTC 与普通模式不提供喜欢功能，因为 Windows 系统媒体控制没有这项命令。

完整控制需要网易云音乐开启一个本机调试端口，端口开启期间存在一定风险，启用前请阅读[数据与隐私](privacy.md#网易云音乐完整控制)中的说明。

- **始终启用**：在"设置 › 音乐 › 播放器 › 网易云音乐"中打开"始终启用完整控制"，确认后网易云会重启一次。这会修改网易云安装目录中 `libcef.dll` 的 2 处字节；改过之后，网易云每次启动都是完整控制，与启动方式无关，不必再逐次启用。关闭开关会恢复原文件，不会关闭网易云，网易云下次启动时回到普通模式。开关打开期间，网易云更新换掉这个文件后，BrimDeck 会自动重新修改，并重启一次网易云。
- 网易云安装在 `C:\Program Files` 等需要管理员权限的目录时，修改文件时 Windows 会请求管理员权限。
- 如果只想临时启用一次，可在音乐页点击"启用完整控制"，或在"设置 › 音乐 › 播放器"中打开"始终显示'启用完整控制'按钮"。

## Apple Music

- **默认**：显示曲目、封面和进度，可以播放、暂停和切歌。
- **完整控制**：在音乐页点击"启用完整控制"并确认后，可以拖动进度、开关随机播放、切换重复模式（关闭、全部重复、单曲重复）。这些功能通过 Windows 的界面自动化操作 Apple Music 窗口中的按钮和进度条实现，因此需要 Apple Music 的主窗口存在；主窗口没有最小化时，使用这些功能会把它带到最前面。完整控制在 BrimDeck 重启前有效。

## 酷狗音乐

- **默认**：需要在酷狗中勾选"设置 › 常规设置 › 播放 › 支持系统播放控件，如锁屏界面"，之后可以显示曲目和封面，以及播放、暂停和切歌。不勾选也不启用完整控制时，BrimDeck 无法读取酷狗。酷狗不向 Windows 提供进度，所以不显示进度，歌词也不能随进度滚动。
- **完整控制**：显示实际进度和更大的封面，歌词随进度滚动，并优先使用酷狗自己的歌词。完整控制不依赖上述酷狗选项。酷狗没有提供设置进度的方法，所以仍然不能拖动进度。
- **启用与关闭**：在"设置 › 播放器 › 酷狗音乐"中打开"始终启用完整控制"，或在普通模式下点击音乐页的"启用完整控制"，确认后酷狗会重启一次。完整控制需要修改酷狗安装目录中 `libcef.dll` 的 9 处字节；改过之后，酷狗每次启动都是完整控制，与启动方式无关。关闭开关会恢复原文件，不会关闭酷狗，酷狗下次启动时回到普通模式。开关打开期间，酷狗更新换掉这个文件后，BrimDeck 会自动重新修改，并重启一次酷狗。
- 酷狗安装在 `C:\Program Files` 等需要管理员权限的目录时，修改文件时 Windows 会请求管理员权限。
- BrimDeck 只读写这 9 处字节。LyricsWall 等工具以同样方式修改过的文件，BrimDeck 直接使用；其中只改了一部分的，启用时只补写其余位置。这 9 处如果被其他工具改成了别的内容，BrimDeck 不会改动文件；此时酷狗如果已由其他方式打开调试端口，BrimDeck 会直接连接。

完整控制会让酷狗打开一个本机调试端口，启用前请阅读[数据与隐私](privacy.md#酷狗音乐完整控制)中的说明。
