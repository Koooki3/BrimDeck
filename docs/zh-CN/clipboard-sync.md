# 剪贴板同步（开发中）

在“设置 → 中转站 → 剪贴板同步”中，可以用三种方式让本机与其他设备互相同步复制的内容。三种方式可以同时使用。

| 方式 | 同步对象 | 内容 |
| --- | --- | --- |
| 局域网 | 另一台装有 BrimDeck 的电脑 | 文字、图片 |
| 微信输入法 | 手机或电脑上的微信输入法 | 文字、图片 |
| 豆包输入法 | 登录同一豆包账号的手机或电脑 | 文字、图片（发送图片有大小限制，见下文） |

连接成功后“自动同步”会自动开启。开启期间，本机新复制的内容会发送给对方，对方复制的内容会写入本机剪贴板；开启历史记录时也会进入 BrimDeck 的剪贴板历史。只同步开启之后新复制的内容，文件、历史记录和常用语不同步。

## 局域网

1. 两台电脑连接同一网络，各自打开“剪贴板同步”，点击局域网的“配对”。
2. 两个窗口都会显示本机的六位配对码。在其中一台输入另一台显示的配对码，配对即完成。

内容在两台电脑之间加密直连，不经过互联网，不需要账号。目前只支持一对电脑。图片以 PNG 传输，单张最多 8 MiB、单边最多 8192 像素。断线期间复制的内容不会在重新连接后补发。

在一台电脑上解除配对时，另一台如果在线，也会同时解除。

电脑离开网络后再回来（例如带走的笔记本）会自动重新连接，网络地址变了也不需要重新配对。微信输入法与豆包输入法的连接同样会在网络恢复后自动重连。

## 微信输入法

微信输入法把这个功能称为“跨设备”，配对码称为“匹配码”。不需要登录微信。

- **输入匹配码**：在手机或另一台电脑上打开微信输入法的设置，进入“跨设备”，点击“查看匹配码”；在 BrimDeck 中点击“关联设备”，输入该匹配码。那台设备如果弹出确认，选择允许。
- **显示本机匹配码**：在 BrimDeck 的关联窗口中切换到“显示本机匹配码”；在那台设备的“跨设备”页面底部点击“关联设备”，输入 BrimDeck 显示的匹配码，再回到 BrimDeck 点击“允许”。

说明：

- 那台设备要在“跨设备”页面开启“跨设备复制粘贴”，它复制的内容才会同步过来；关闭后 BrimDeck 不再收到。个人词库、常用语、AI 录音笔等其他开关与 BrimDeck 无关。
- 微信输入法收到图片后，写入剪贴板的是一个图片文件，只接受图片数据的程序可能无法直接粘贴。这是微信输入法自己的做法。
- 其他设备可以给本机改名。改名后，卡片中会显示“本机在微信输入法中显示为……”。本机名称只能在关联之前修改。
- 其他设备把本机移除后，状态显示“已被其他设备解除关联”。此时点击“解除关联”，再重新关联。
- 在 BrimDeck 中解除关联时，本机也会从其他设备的“跨设备 → 我的设备”中删除。如果网络不通，BrimDeck 会提示无法删除；这时仍可解除关联，之后请在那些设备上手动删除本机，否则再次关联后列表里会出现两个本机。
- 图片支持 PNG 和 JPEG，单张最多 16 MiB。

### 从文件中转站发送文件

在 BrimDeck 中关联手机后，右键点击文件并选择「分享」。文件同时支持 Windows 分享时，将鼠标移到「分享」上，再选择「通过微信输入法发送」或「分享到更多应用」。Windows 快捷方式可以作为文件发送，手机收到的是快捷方式本身。

在发送窗口选择已配对的接收设备，或显示一次性二维码供对方扫描。两台设备不在同一局域网时，文件经微信输入法的服务器中转。可以一次发送多个文件，暂不支持文件夹。

### 接收已配对设备发来的文件

在另一台设备的微信输入法中选择 BrimDeck 所在的设备。BrimDeck 会显示发送方名称。也可以点击文件中转站顶部的「接收微信输入法文件」查看本机设备名并等待邀请。点击「接收…」后选择文件夹，也可以点击「拒绝」。文件校验通过后会保存到所选位置，并出现在文件中转站。同名文件会自动编号。一次接收多个文件时，窗口显示文件数和整体进度。

## 豆包输入法

豆包输入法把这个功能称为“超级互传”，同一账号下的设备互相同步。

1. 在 BrimDeck 中点击“登录”，在打开的浏览器窗口中登录豆包账号。登录使用电脑上已安装的 Chrome 或 Edge 的独立窗口，登录完成后窗口自动关闭。
2. 在手机或另一台电脑的豆包输入法中登录同一账号，并开启“超级互传”。

登录后 BrimDeck 会把本机的互传开关打开一次。之后可以在豆包输入法“超级互传”页面的已关联设备中关闭或重新开启本机：关闭后 BrimDeck 停止同步，状态显示“此设备的互传开关未开启”；重新开启后自动恢复，不需要重新登录。在 BrimDeck 中退出登录时，本机会从豆包的已关联设备中消失。

退出时没有被移除的设备（例如重装前登录的 BrimDeck）会一直留在列表里，豆包输入法自己不能删除设备。登录后展开豆包卡片底部的“高级”，可以逐台移除账号下的其他设备。正常情况下应当在那台设备上退出登录；被移除的设备如果还在使用，需要在它上面重新登录。

文字连同格式一起同步（例如编号列表、加粗）；微信输入法和局域网只同步纯文字。发送图片目前最多 2 MiB，超过时状态显示“图片过大，未发送”；接收图片单张最多 10 MiB。

电脑上已经安装豆包输入法并开启了“超级互传”时，它自己就在同步剪贴板，不需要再在 BrimDeck 中登录豆包。

## 数据与隐私

- 连接信息用 Windows 当前用户的数据保护机制加密，保存在 BrimDeck 数据目录中。BrimDeck 不读取已安装输入法的账号文件。换电脑后需要重新连接。
- 微信输入法与豆包输入法的同步经过各自的服务器，局域网同步不经过任何服务器。
- 剪贴板设置中“不记录的应用”和密码管理器的隐私标记同样适用：这些复制不会被同步。
- 微信输入法与豆包输入法的连接方式不是官方公开接口，官方更新后可能失效。
- 数据目录的 `clipboard-sync\events.log` 记录同步的经过，用于查找问题：时间、内容的类型与大小、设备和来源应用的名称、服务返回的错误码。其中不含复制的内容，超过 256 KB 时删去较早的一半。
